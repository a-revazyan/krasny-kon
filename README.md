Чистые HTML + CSS + JS, без сборщиков и внешних зависимостей.

## Архитектура сетки и контракт будущего ИИ-ассистента (`P0-V`)

Главная страница разделена на независимую 12-колоночную оболочку (`.page-shell`), область основного контента (`.page-main`) и необязательный слот ассистента (`.page-assistant`).

### Состояния оболочки (`data-ai-enabled` на `<body>`)
1. **По умолчанию (`data-ai-enabled="false"`):**
   - `<aside id="ai-assistant-slot" data-ai-slot hidden></aside>` скрыт (`display: none`), занимает `0px` и отсутствует в дереве доступности.
   - `.page-main` занимает все 12 колонок. Никаких иконок чата, заглушек или надписей «скоро» на публичной странице нет.
2. **При подключении будущего модуля (`data-ai-enabled="true"` и снятии `hidden` со слота):**
   - **Desktop `>= 1360px`:** `9` колонок основной контент + `3` колонки правая sticky-панель ИИ под шапкой.
   - **Desktop `1024–1359px`:** `8` колонок основной контент + `4` колонки правая sticky-панель ИИ (чтобы ширина панели оставалась комфортной `>= ~340px`).
   - **Tablet / Mobile `< 1024px`:** `1` колонка основной контент; слот ассистента открывается отдельно как боковая панель без смещения контента и перекрытия CTA в закрытом состоянии.

### Адаптация контента через CSS Container Queries
На `.page-main` задано `container-type: inline-size; container-name: main;`. Все сетки и типографика главной адаптируются через `@container main (...)` и единицы `cqi` / `clamp()`, а не через ширину viewport. Благодаря этому при сужении `.page-main` после включения правой колонки ИИ все секции перестраиваются автоматически без переписывания вёрстки.

### Стабильные идентификаторы и формат контекста
В DOM главной расставлены постоянные идентификаторы, не зависящие от визуального порядка блоков:
- Страница: `data-page-id="home"` на `<body>`
- Состояние ИИ: `data-ai-enabled="false"` на `<body>`
- Слот монтирования ИИ: `[data-ai-slot]` (`#ai-assistant-slot`)
- Секции: `data-section-id` (`header`, `hero`, `slogan`, `projects`, `services`, `subscription`, `express`, `who`, `process`, `packages`, `contacts`, `footer`)
- Кейсы: `data-project-id` (`olomolo`, `ochen-molochen`, `zhelen`, `yablochny-spas`)
- Услуги: `data-service-id` (`branding`, `packaging`, `web-design`, `ui-ux`, `design-subscription`, `design-subscription-service`, `creative`, `neurovideo`)

В `js/main.js` предусмотрен read-only хелпер `window.KK_CONTEXT.getSnapshot()`, возвращающий массив объектов публичного контекста в целевом формате:

```json
{
  "pageId": "home",
  "sectionId": "projects",
  "projectId": "olomolo",
  "serviceId": null,
  "title": "Оломоло",
  "publicText": "...",
  "url": "https://redkon.ru/#projects"
}
```

> В `P0-V` не подключаются LLM/API, база знаний, наблюдатели активной секции и публичный чат. Тестовый слот доступен строго по параметру `?ai-preview=1` и автоматически блокируется на production-домене `redkon.ru`.

- **Слоган «Кирпичики»:** сохранён и переведён на контейнерную CSS Grid без перекрытий текста.
- **Проекты:** 3D-куб и бегущая строка удалены; собрана регулярная сетка `2×2` с приоритетными кейсами (**Оломоло**, **Очень молочен**, **Желен**, **Яблочный спас**), обложка и описание «Оломоло» взяты из Figma, фиктивные ссылки `href="#"` убраны.
- **Услуги:** сгруппированы в «Создание бренда» и «Развитие бренда», сохранены все направления, включая «Нейровидео».
- **Дизайн-подписка, Экспресс-продукты, Пакеты и Процесс:** убран весь `Lorem ipsum`, добавлены актуальные ориентиры цен из маркетингового плана и черновые описания/составы «Результата» для согласования.
- **Для кого работаем:** сохранены все 4 интерактивные сцены (коробки, бутылки, карточки товаров, плитки с конём), переписаны без CSS `zoom` с адаптацией под контейнер.
- **Контакты, футер и форма:** актуализирован год реквизитов (`© 2011–2026`), убраны битые ссылки `#` на соцсети (оставлен слот под ВК и MAX), форма в preview-ветке явно помечена как тестовая (`data-form-mode="preview"`).

## Развёртывание, preview и план отката

### Текущий статус (preview)
Изменения находятся в отдельной ветке `feat/homepage-v1-visual`. Ветка `main` (автодеплой на GitHub Pages) **не изменена**.

### Важно до merge в `main`
- **Блокер коммерческого запуска (`P0-F`):** форма сейчас работает в тестовом режиме без серверной доставки заявок. Не вливать в `main` до подключения CRM/бэкенда (`P0-F`) либо без отдельного согласования временного отключения формы и замены CTA на прямой контакт.
- Получить и добавить реальные ссылки на **ВКонтакте** и **MAX**.
- Согласовать/отредактировать черновые тексты в «Экспресс-продуктах», «Пакетах» и «Процессе».

### План отката
Если после публикации изменений потребуется мгновенный откат к предыдущей версии главной страницы:
```bash
git checkout main
git revert <commit-hash-merge>
git push origin main
```
Либо до merge достаточно просто переключиться обратно на ветку `main`: `git checkout main`.
