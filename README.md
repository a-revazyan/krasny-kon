# Красный конь — сайт

Главная страница по макету Figma «красный конь»: фреймы **Desktop** (1280px), **Tablet** (768px) и **mobile** (412px).
Чистые HTML + CSS + JS, без сборщиков и зависимостей.

## Как открыть

```bash
cd ~/Desktop/"красный конь"
python3 -m http.server 5178
```

Затем открыть http://localhost:5178

## Структура

```
index.html          — разметка всей страницы
css/style.css       — стили: десктоп, затем блоки @media для планшета и телефона
js/main.js          — масштаб, шум, анимации и интерактив
assets/fonts/       — Monoid Bold, Golos UI (Regular / Medium / Bold) в woff2
assets/img/         — ассеты из Figma (SVG, WebP)
```

## Раскладки

| Ширина экрана | Макет | 1rem = 10px макета при ширине |
|---|---|---|
| от 1024px | Desktop | 1280 |
| 600–1023px | Tablet | 768 |
| до 599px | mobile | 412 |

Внутри каждой раскладки страница масштабируется пропорционально (масштаб задаёт `js/main.js`).

Раскладка планшета и телефона взята из их макетов, а тексты, цены и иконки на всех экранах — с десктопного макета: там актуальная информация, в адаптивах она могла устареть.

## Что реализовано по макету и аннотациям Figma

- **Шапка** фиксирована: прячется при скролле вниз и появляется при скролле вверх.
- **Первый экран**: «Студия дизайна» уезжает через 2 с. Страница не листается, пока не нажата «Play».
  После этого карточки «Брендинг → Web UX/UI → Дизайн-подписка» выезжают слева по скроллу или по кнопкам «Далее» / «Что ещё?».
  «Обсудим?» открывает форму.
- **Шум (Noise overlay)** лежит поверх всего макета и подобран по пикселям под эффект Noise из Figma.
- **Наши проекты**: 3D-куб с картинками проектов крутится сам (пауза при наведении, клик — следующий), на фоне бегущая строка.
- **Экспресс-продукты / Пакеты**: ряд карточек можно тянуть мышью, «Результат» раскрывается.
- **Услуги**: аккордеон, одновременно открыта одна услуга.
- **Для кого работаем**: коробки приподнимаются при наведении, в бутылки можно «стрелять» кликом, карточки товаров поворачивают иконку, кони краснеют.
- **Процесс и сроки**: этапы переключаются наведением или кликом, шкала заполняется.
- **Меню** (бургер) и **поп-ап «Познакомимся?»** с проверкой полей. После отправки показывается «Спасибо за письмо!» с конвертом.
  Из карточек услуг и пакетов форма открывается в варианте «Услуга: название» (компонент «popup услуг»). Название услуги уходит в заявку.
- **Планшет и телефон**: первый экран — текст и горизонтальная лента карточек со стрелкой-индикатором прокрутки. Блоки «Для кого работаем» — карточки с иллюстрацией внутри, процесс — описание над списком этапов.

## Нужно уточнить или дополнить

1. Код куба из codepen (lector/pen/LYVdyrg) не открылся: Cloudflare блокирует доступ. Куб написан с нуля; если нужен именно тот вариант, пришлите код.
2. Названия и описания проектов для куба: в макете стоят заглушки «Название / Lorem ipsum». Их нужно заменить в `js/main.js` (массив `PROJECTS`).
3. Тексты карточек экспресс-продуктов и пакетов: сейчас Lorem ipsum. Пункты «Результат» у всех карточек одинаковые.
4. Цены услуг: в макете есть только «от 120 000 ₽» у веб-дизайна. У остальных временно стоит «Стоимость по запросу».
5. Процесс и сроки: заполнен только «Бриф — 1 день». Сроки и описания остальных этапов нужно дописать в `js/main.js` (массив `STAGES`).
6. Отправка формы пока не подключена: нужно решить, куда отправлять заявки (почта, CRM или Telegram). Место для подключения помечено `TODO` в `js/main.js`.
7. Ссылки на соцсети, «Подробнее» и «Смотреть все проекты» пока ведут в никуда (`#`).
8. В футере и меню стоит «© 2011-2025 Digital интегратор WebCat, ИНН 5614087228, ООО ВЕБКАТ». Стоит проверить, правильные ли это реквизиты.
9. По прототипу на планшете и телефоне «Студия дизайна» тоже уезжает через 2 секунды. Но там её ничем не закрывают, и наверху оставалась бы пустая полоса. Поэтому на этих экранах текст оставлен на месте, анимацию можно включить.
